```bash title="Install, set your key, done"
npm i -g @muthuishere/jevx
export TYPESAFE_API_KEY=...
```

Get a key in the [TypeSafe console](https://console.typesafe.ai/keys), or point jevx at [your own endpoint](/jevx/start/getting-started/#optional-your-own-endpoint).

```console title="Your agent, or you"
$ jevx filter "Is this line an error an on-call engineer would act on?" < app.log
2026-09-27 10:03:40 ERROR payment gateway timeout after 30s (order 4021)
2026-09-27 10:04:02 FATAL db connection refused: too many clients

$ jevx is "Does this command overwrite history on a shared remote branch?" --in "git push --force origin main"
yes 0.96
```

<CardGrid>
	<Card title="Your agents already know it" icon="seti:shell">
		One install teaches Claude Code and Codex when to ask Jev, and what to do with `yes`, `no` or `unsure`.
	</Card>
	<Card title="Your instructions are the context" icon="open-book">
		It reads the `## Jev` section of the AGENTS.md / CLAUDE.md you already keep. Nothing new to maintain.
	</Card>
	<Card title="Judge against your own notes" icon="document">
		`--memory` sends the best-matching sections of your docs after the item: on 143 held-out claims a 0.4B local model went from AUC 0.48 to 0.76. `--memory-strict` catches 70 of 72 changed numbers, at a cost in wrongly failed true claims.
	</Card>
	<Card title="Repeat calls are free" icon="rocket">
		Answers are kept on your machine, keyed by a hash, so asking the same thing again returns in milliseconds and costs nothing. On by default; `--fresh` asks again.
	</Card>
	<Card title="Guards at agent events" icon="setting">
		Stop an `rm -rf`, flag an injected web page, check a turn before it is handed back. Off until you turn it on.
	</Card>
</CardGrid>
